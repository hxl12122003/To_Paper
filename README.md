# To Paper: AI-Powered Academic Literature & Writing Assistant

## 📖 Overview
To Paper is an end-to-end AI system designed for academic research. It bridges the gap between massive literature ingestion and high-quality manuscript generation by building structured, traceable knowledge bases (LLM Wiki) from raw PDFs.

## 🧩 Core Modules
1. **Literature Search & Mining**: Multi-dimensional keyword matrix generation and abstract scoring to filter massive literature.
2. **Ingestion & Knowledge Base Construction**: Automatically parses PDFs, extracts 8 key academic elements, and builds a structured LLM Wiki.
3. **Manuscript Generation**: Assembles retrieved knowledge into structured academic manuscripts with citation tracing.
